# Changelog

All notable changes to this project will be documented in this file.

This changelog is automatically generated by [semantic-release](https://semantic-release.gitbook.io/).

## [0.3.0](https://github.com/i11v/effect-jmap/releases/tag/v0.3.0) (2025-11-30)

### Features

* Add `JMAPLive(sessionUrl, bearerToken)` convenience layer bundling HTTP client, JMAP client, and all services
* Add `JMAPLiveWithConfig(config)` variant supporting custom configuration

### Refactoring

* Refactor service definitions to use `Context.Tag` class pattern
* Improve documentation with usage examples

## [0.2.0](https://github.com/i11v/effect-jmap/releases/tag/v0.2.0) (2025-11-17)

### Features

* Add email submission capability for JMAP with schemas and full validation
* Add comprehensive test coverage (628 cases for submission schemas, 476 for EmailSubmission service)
* Add capability negotiation system for JMAP sessions
* Add IdGenerator service for Effect-idiomatic ID generation

### Refactoring

* Refactor all services (Email, EmailSubmission, Mailbox) to use Effect-idiomatic IdGenerator pattern

## [0.1.0](https://github.com/i11v/effect-jmap/releases/tag/v0.1.0) (2025-10-04)

### Features
